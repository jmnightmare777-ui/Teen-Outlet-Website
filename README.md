# Teen Outlet Ministries — Professional Website

This package is a complete, responsive static website using Teen Outlet's supplied logo and branding.

## Included pages

- `index.html` — home page
- `events.html` — upcoming events and calendar downloads
- `launchpad.html` — Launchpad ministry
- `new-here.html` — first-visit and parent information
- `give.html` — Cash App giving page using **$TeenOutlet21**
- `404.html` — branded not-found page

## Preview locally

Double-click `index.html`. No installation or build step is required.

## Publish it

The easiest options are:

1. Netlify Drop: drag the entire unzipped folder into Netlify's deploy area.
2. Cloudflare Pages: upload the folder as a static site.
3. GitHub Pages: add the files to a repository and enable Pages.

After publishing, connect a custom domain such as `teenoutlet.org` or another available address.

## Updating the site

- Contact details and the Cash App cashtag are documented in `site-config.js`.
- Page text is in the corresponding `.html` file.
- Main styling is in `styles.css`.
- Interaction and the next-event countdown are in `app.js`.
- Event images are in `assets/`.
- Calendar downloads are the `.ics` files in the main folder.
